# Methodology changelog

## 2026-08-18 — major conceptual correction

### Previous primary question
Search contemporaneous independent-observatory plates for detections at the same celestial coordinates.

### Problem identified
That is an excellent test for distant/astronomical sources, but is not a fair primary test of the proposed GEO/high-Earth reflected-light hypothesis because geographically separated observers can see substantial parallax, and specular reflection is directional.

### New structure
- preserve same-sky matching as **Branch A**;
- add independent same-observatory before/positive/after transient-population replication as **Branch B**;
- add parallax-aware simultaneous matching as **Branch C**.

### Additional timing change
Record actual exposure-overlap intervals for every pair, not only midpoint separation.

### Candidate stop rule
Any strong candidate triggers completion of that candidate's escalation analysis and an immediate pause before the next case.

### Correlation priority
Previously reported nuclear-test timing, Earth-shadow, geomagnetic and UAP metadata may determine processing order only. They may not change thresholds, inclusion criteria or disposition standards.
